# PS Gift Card Stock Monitor 🎮

בודק ברציפות את כל כרטיסי המתנה של PlayStation Store הודו באמאזון הודו (12 מוצרים, ראו `products.txt`), ושולח הודעת טלגרם ברגע שאחד מהם חוזר למלאי.

- 🟢 הודעה מיידית עם **קישור ישיר להוספה לעגלה** + המחיר (ותזכורת כל דקה כל עוד במלאי)
- 🔴 הודעה אם המוצר אוזל שוב
- 🛡️ אם אמאזון חוסמת (captcha / 503) — עוצר לכמה שניות ואז ממשיך לבד
- 💻 ב-Windows מונע מהמחשב להיכנס לשינה כל עוד הסקריפט רץ

## הרצה על המחשב (Windows)

1. התקן [Python](https://www.python.org/downloads/) (3.10 ומעלה) — בהתקנה סמן ✅ **Add python.exe to PATH**.
2. הורד את הקוד: **Code → Download ZIP** וחלץ לתיקייה (או `git clone`).
3. בתיקייה, העתק את `.env.example` לקובץ בשם `.env` ומלא את `TELEGRAM_BOT_TOKEN` ו-`TELEGRAM_CHAT_ID`.
   (ה-Secrets ב-GitHub משמשים רק את GitHub Actions — המחשב קורא מ-`.env`.)
4. לחיצה כפולה על **`start.bat`**. הוא מתקין את מה שצריך, מריץ, ומפעיל מחדש אם משהו קורס.

תוך שנייה תגיע לטלגרם הודעת "👀 Stock monitor started" עם רשימת המוצרים.

בחלון יופיע לוג. כל 10 דקות תופיע שורת `Alive` עם מספר הבדיקות והחסימות.

## קצב בדיקה

`CHECK_INTERVAL` = שניות בין בקשה לבקשה (ברירת מחדל `1`). הבקשות עוברות בסבב על כל המוצרים, כך שכל מוצר נבדק כל `CHECK_INTERVAL × מספר המוצרים` — עם 12 מוצרים ושנייה אחת, כל מוצר נבדק כל ~12 שניות.

- רואים הרבה `blocks` בשורת ה-`Alive`? העלו ל-`2`–`3`. בדיקות שנחסמות לא בודקות כלום.
- רוצים מהר יותר למוצר מסוים? הוסיפו `#` בתחילת השורה של מוצרים שלא מעניינים אתכם ב-`products.txt` — פחות מוצרים = כל אחד נבדק יותר מהר.

## עריכת רשימת המוצרים

`products.txt` — שורה לכל מוצר: `ASIN | שם`. ה-ASIN הוא הקוד אחרי `/dp/` בכתובת המוצר באמאזון.

## הגדרות (בקובץ `.env`)

| משתנה | ברירת מחדל | תיאור |
|---|---|---|
| `CHECK_INTERVAL` | `1` | שניות בין בקשות |
| `REMIND_EVERY` | `60` | כל כמה שניות לשלוח תזכורת כשמוצר במלאי |
| `PRODUCTS_FILE` | `products.txt` | קובץ רשימת המוצרים |
| `MAX_RUNTIME` | `0` | זמן ריצה מקסימלי בשניות (`0` = לנצח) |

## הרצה ב-Linux / Mac

```bash
pip install -r requirements.txt
cp .env.example .env   # ומלא את הערכים
python monitor.py
```

## GitHub Actions (אופציונלי)

ה-workflow קורא את `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` מה-Secrets. ריצה מתוזמנת רציפה דורשת repo ציבורי (~43,000 דקות בחודש); ב-repo פרטי הריצה המתוזמנת מדלגת ורק הפעלה ידנית עובדת. אם המחשב רץ — אין צורך בזה.
